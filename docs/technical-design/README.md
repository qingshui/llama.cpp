## 架构概览图

```
┌─────────────────────────────────────────────────────────────┐
│                    应用层 (Applications)                     │
│  llama-cli | llama-server | llama-batched | examples...     │
├─────────────────────────────────────────────────────────────┤
│                    公共库层 (Common Library)                  │
│  common/ - 采样器、聊天模板、参数解析、工具函数               │
├─────────────────────────────────────────────────────────────┤
│                   核心推理层 (llama Core)                    │
│  src/ - 模型加载、KV 缓存、计算图、批处理、内存管理           │
├─────────────────────────────────────────────────────────────┤
│                  张量库层 (GGML Tensor Lib)                  │
│  ggml/ - 张量操作、自动微分、优化算法、后端抽象              │
├─────────────────────────────────────────────────────────────┤
│                   硬件加速层 (Backends)                      │
│  CPU/GPU/CUDA/Metal/Vulkan/SYCL/OpenCL...                  │
└─────────────────────────────────────────────────────────────┘
```
