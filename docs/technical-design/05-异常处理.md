# llama.cpp 技术设计文档

## 第五部分：异常处理

### 5.1 错误处理哲学

llama.cpp 采用 C/C++ 风格的错误处理机制，主要特点：

1. **返回值检查**: 通过函数返回值表示成功/失败
2. **断言机制**: 使用 `GGML_ASSERT` 进行运行时检查
3. **日志系统**: 通过日志记录错误信息
4. **状态枚举**: 使用 `ggml_status` 表示操作状态

**设计原则：**
- 不在库代码中抛出 C++ 异常
- 调用者负责检查返回值
- 致命错误使用断言终止
- 可恢复错误通过返回值通知

### 5.2 错误状态枚举

#### 5.2.1 ggml_status

```cpp

    GGML_STATUS_ALLOC_FAILED = -2,  // 内存分配失败
    GGML_STATUS_FAILED       = -1,  // 通用失败
    GGML_STATUS_SUCCESS      =  0,  // 成功
    GGML_STATUS_ABORTED      =  1,  // 操作被中止
```

#### 5.2.2 返回值检查模式

```cpp
// 典型错误处理模式
enum ggml_status status = ggml_backend_graph_compute(backend, graph);

switch (status) {
    case GGML_STATUS_SUCCESS:
        // 成功，继续执行
        break;
    case GGML_STATUS_ALLOC_FAILED:
        // 内存不足，尝试释放或减小批处理大小
        fprintf(stderr, "error: memory allocation failed\n");
        return false;
    case GGML_STATUS_FAILED:
        // 计算失败，检查输入数据
        fprintf(stderr, "error: computation failed\n");
        return false;
    case GGML_STATUS_ABORTED:
        // 操作被中止（如回调返回 false）
        fprintf(stderr, "info: operation was aborted\n");
        return false;
}
```

#### 5.3.1 GGML_ASSERT

### 5.6 资源管理

#### 5.6.1 RAII 模式

```cpp
// 使用智能指针管理资源
class llama_model_guard {
    llama_model * model;

public:
    llama_model_guard() : model(nullptr) {}

    explicit llama_model_guard(llama_model * m) : model(m) {}

    ~llama_model_guard() {
        if (model) {
            llama_free_model(model);
        }
    }

    // 禁止拷贝
    llama_model_guard(const llama_model_guard &) = delete;
    llama_model_guard & operator=(const llama_model_guard &) = delete;

    // 允许移动
    llama_model_guard(llama_model_guard && other) noexcept
        : model(other.model) {
        other.model = nullptr;
    }

    llama_model_guard & operator=(llama_model_guard && other) noexcept {
        if (this != &other) {
            if (model) llama_free_model(model);
            model = other.model;
            other.model = nullptr;
        }
        return *this;
    }

    llama_model * get() const { return model; }
    llama_model * release() {
        llama_model * m = model;
        model = nullptr;
        return m;
    }
};

// 使用方式

}
```

### 5.7 边界检查

#### 5.7.1 数组边界检查

```cpp
// src/llama-batch.cpp
void llama_batch_add(
    struct llama_batch & batch,
    llama_token token,
    llama_pos pos,
    const std::vector<llama_seq_id> & seq_ids)
{
    // 边界检查
    if (batch.n_tokens >= batch.n_tokens_max) {
        LLAMA_LOG_ERROR("%s: batch is full (%d >= %d)\n",
                       __func__, batch.n_tokens, batch.n_tokens_max);
        GGML_ASSERT(false);  // 或返回错误
        return;
    }

    // 安全访问
    batch.token[batch.n_tokens] = token;
    batch.pos[batch.n_tokens] = pos;
    batch.n_seq_id[batch.n_tokens] = seq_ids.size();

    for (size_t i = 0; i < seq_ids.size(); i++) {
        GGML_ASSERT(i < batch.n_seq_id_max);  // 防止越界
        batch.seq_id[batch.n_tokens][i] = seq_ids[i];
    }

    batch.n_tokens++;
}
```

```cpp
bool llama_context::alloc_memory() {
    // 尝试分配主缓冲区
    m_compute_buffer = ggml_backend_alloc_buffer(m_sched, compute_size);
    if (m_compute_buffer == nullptr) {
        LLAMA_LOG_ERROR("%s: failed to allocate compute buffer "
                       "(size=%zu)\n", __func__, compute_size);

        // 尝试减小分配
        size_t reduced_size = compute_size / 2;
        LLAMA_LOG_INFO("%s: trying reduced size %zu\n",
                      __func__, reduced_size);

        m_compute_buffer = ggml_backend_alloc_buffer(m_sched, reduced_size);
        if (m_compute_buffer == nullptr) {
            LLAMA_LOG_FATAL("%s: failed to allocate even reduced buffer\n",
                           __func__);
            return false;
        }
    }

    // 检查分配是否足够
    size_t actual_size = ggml_backend_buffer_get_size(m_compute_buffer);
    if (actual_size < required_size) {
        LLAMA_LOG_WARN("%s: allocated buffer (%zu) is smaller than "
                      "required (%zu)\n", __func__, actual_size, required_size);
        // 可能影响性能，但不一定是致命错误
    }

    return true;
}
```

### 5.9 并发错误处理

#### 5.9.1 线程同步错误

```cpp
// tools/server/server-queue.cpp
class server_queue {
    std::queue<server_task> queue;
    std::mutex mtx;
    std::condition_variable cv;
    bool shutdown = false;

public:
    bool send(const server_task & task) {
        std::unique_lock<std::mutex> lock(mtx);

        if (shutdown) {
            LLAMA_LOG_ERROR("%s: queue is shutting down\n", __func__);
            return false;
        }

        try {
            queue.push(task);
        } catch (const std::exception & e) {
            LLAMA_LOG_ERROR("%s: failed to push task: %s\n",
                           __func__, e.what());
            return false;
        }

        cv.notify_one();
        return true;
    }

    bool receive(server_task & task, int timeout_ms) {
        std::unique_lock<std::mutex> lock(mtx);

        if (timeout_ms < 0) {
            // 无限等待
            cv.wait(lock, [this] {
                return !queue.empty() || shutdown;
            });
        } else {
            // 超时等待
            bool success = cv.wait_for(lock,
                std::chrono::milliseconds(timeout_ms),
                [this] { return !queue.empty() || shutdown; });

            if (!success) {
                LLAMA_LOG_DEBUG("%s: receive timeout\n", __func__);
                return false;  // 超时，非错误
            }
        }

        if (shutdown && queue.empty()) {
            LLAMA_LOG_INFO("%s: queue is shutting down\n", __func__);
            return false;
        }

        if (queue.empty()) {
            // 假唤醒
            return false;
        }

        task = queue.front();
        queue.pop();
        return true;
    }
};
```

```cpp
    if (graph == nullptr) {
        return GGML_STATUS_FAILED;
    }

    for (int i = 0; i < graph->n_nodes; i++) {
        ggml_tensor * node = graph->nodes[i];
        if (node->data == nullptr) {
```
