# llama.cpp 技术设计文档

## 第一部分：架构设计

### 1.1 项目概述

llama.cpp 是一个用纯 C/C++ 实现的大型语言模型（LLM）推理框架，旨在在各种硬件平台上以最小的设置实现高性能 LLM 推理。

**核心目标：**
- 在广泛的硬件上实现高性能 LLM 推理（从消费级设备到数据中心）
- 最小化的设置和依赖
- 支持多种模型架构和量化格式
- 提供 C/C++ API 以及服务器和命令行工具

### 1.2 整体架构分层

llama.cpp 采用分层架构设计，从底层到高层依次为：

```
┌─────────────────────────────────────────────────────────────┐
│                    应用层 (Applications)                     │
│  llama-cli | llama-server | llama-batched | examples...     │
├─────────────────────────────────────────────────────────────┤
│                    公共库层 (Common Library)                  │
│  common/ - 采样器、聊天模板、参数解析、工具函数               │
├─────────────────────────────────────────────────────────────┤
│                   核心推理层 (llama Core)                    │
│  src/ - 模型加载、KV 缓存、计算图、批处理、内存管理           │
├─────────────────────────────────────────────────────────────┤
│                  张量库层 (GGML Tensor Lib)                  │
│  ggml/ - 张量操作、自动微分、优化算法、后端抽象              │
├─────────────────────────────────────────────────────────────┤
│                   硬件加速层 (Backends)                      │
│  CPU/GPU/CUDA/Metal/Vulkan/SYCL/OpenCL...                  │
└─────────────────────────────────────────────────────────────┘
```

### 1.6 设计原则

1. **最小依赖**: 纯 C/C++ 实现，无外部依赖
2. **性能优先**: 针对各种硬件架构优化（ARM NEON、AVX、CUDA、Metal）
3. **内存效率**: 静态内存分配、量化支持、混合精度计算
4. **模块化**: 清晰的分层和模块边界
5. **可扩展性**: 支持 100+ 种模型架构
6. **跨平台**: 支持 Windows、Linux、macOS、Android、iOS

### 1.7 支持的硬件后端

| Vulkan | 跨平台 GPU | 跨平台 GPU 支持 |
| SYCL | Intel/AMD GPU | 基于 SYCL 的 GPU 加速 |

| ROCm | AMD GPU | AMD GPU 支持 |
| BLAS | CPU 加速 | BLAS 库加速 |
