## 第三部分：数据结构

### 3.1 核心数据结构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    公共数据结构                             │
│  llama_token | llama_pos | llama_seq_id | llama_batch       │
├─────────────────────────────────────────────────────────────┤
│                    模型数据结构                             │
│  llama_model | llama_vocab | llama_hparams                  │

```

### 3.2 基础类型定义

#### 3.2.1 Token 相关类型

```cpp
// include/llama.h

// Token ID 类型
typedef int32_t llama_token;

// 特殊 token 值
#define LLAMA_TOKEN_NULL -1  // 空 token

// Token 类型枚举
enum llama_token_type {
    LLAMA_TOKEN_TYPE_UNDEFINED    = 0,
    LLAMA_TOKEN_TYPE_NORMAL       = 1,  // 普通 token
    LLAMA_TOKEN_TYPE_UNKNOWN      = 2,  // 未知 token (<unk>)
    LLAMA_TOKEN_TYPE_CONTROL      = 3,  // 控制 token (<bos>, <eos>)
    LLAMA_TOKEN_TYPE_USER_DEFINED = 4,  // 用户定义 token
    LLAMA_TOKEN_TYPE_UNUSED       = 5,  // 未使用 token
    LLAMA_TOKEN_TYPE_BYTE         = 6,  // 字节 token
};

// Token 属性位掩码
enum llama_token_attr {
    LLAMA_TOKEN_ATTR_UNDEFINED    = 0,
    LLAMA_TOKEN_ATTR_UNKNOWN      = 1 << 0,
    LLAMA_TOKEN_ATTR_UNUSED       = 1 << 1,
    LLAMA_TOKEN_ATTR_NORMAL       = 1 << 2,
    LLAMA_TOKEN_ATTR_CONTROL      = 1 << 3,  // 特殊 token
    LLAMA_TOKEN_ATTR_USER_DEFINED = 1 << 4,
    LLAMA_TOKEN_ATTR_BYTE         = 1 << 5,
    LLAMA_TOKEN_ATTR_NORMALIZED   = 1 << 6,  // 是否需要归一化
    LLAMA_TOKEN_ATTR_LSTRIP       = 1 << 7,  // 左侧去除空格
    LLAMA_TOKEN_ATTR_RSTRIP       = 1 << 8,  // 右侧去除空格
    LLAMA_TOKEN_ATTR_SINGLE_WORD  = 1 << 9,  // 是否作为单个词处理
};
```

### 3.5 KV 缓存数据结构

#### 3.5.1 KV 单元格

```cpp
// src/llama-kv-cells.h
template<typename T>
struct llama_kv_cell {
    T pos;                    // 位置
    llama_seq_id seq_id;      // 序列 ID
    bool is_empty;            // 是否为空
    std::set<llama_seq_id> seq_ids;  // 多序列支持

    bool empty() const {
        return is_empty;
    }

    bool has_seq_id(llama_seq_id id) const {
        return seq_ids.count(id) > 0;
    }

    void add_seq_id(llama_seq_id id) {
        seq_ids.insert(id);
    }

    void clear() {
        is_empty = true;
        seq_ids.clear();
    }
};
```
